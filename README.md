## Features

- **Hand-Drawn Sketch Aesthetic:** Dynamic jitter effects that make the board lines, green X’s, and blue O’s look like traditional hand-drawn frames.
- **Two-Player Local Fun:** Take turns locally matching wits (Green X vs. Blue O).
- **Zero Dependencies:** Runs natively using standard Python modules.
